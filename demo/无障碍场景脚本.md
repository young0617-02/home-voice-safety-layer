# 无障碍场景演示脚本（F-014）

> 场景：**王奶奶，78 岁，独居，视力退化、不愿触屏**。
> 演示目的不是"语音助手多聪明"，而是**哪些动作它拒绝替她做**。
> 全部设备为模拟实体（`devices/inventory.md`），不接任何真实负载。

## 一、盲跑方式（A11：无未记录手工步骤）

```bash
# 0) 前置：Python 3.11+，装依赖
pip install -r requirements.txt

# 1) 决策层自检（不需要 Home Assistant、不需要麦克风）
python -m hvsl.cli doctor

# 2) 跑完整演示脚本（13 步，退出码 0 即全部符合预期）
python -m hvsl.cli demo
#    明细落盘：var/demo_run.json

# 3) 想自己说一句：
python -m hvsl.cli chat
#    你说> 打开客厅大灯
#    你说> 解锁入户门锁      -> [待确认] 未确认前不下发
#    你说> 确认              -> 释放上一步
#    你说> /audit <trace_id> -> 反查这次决策的全部留痕

# 4) 有 faster-whisper venv 时加语音输入（音频不出本机）：
python -m hvsl.cli listen 一句话.wav

# 5) 红线与评测复跑：
python -m pytest -q
python evals/judge.py -v
python scripts/mutate.py
```

## 二、演示台词与预期（与 `demo/demo_script.json` 一一对应）

| # | 说 | 系统反应 | 为什么这样设计 |
| --- | --- | --- | --- |
| 1 | 打开客厅大灯 | 直接执行并回读 | 低风险单设备 |
| 2 | 把客厅空调调到二十六度 | 直接执行 | 参数化指令 |
| 3 | 关掉客厅大灯，然后打开卧室主灯 | 两步按序执行 | 起夜动线的多步编排 |
| 4 | 打开电暖器 | **先问**"这是大功率负载上电，确认吗？"→ 确认后执行 | 大功率插座上电属危险动作 |
| 5 | 打开燃气阀 | **直接拒绝**，提示人工现场操作 | 燃气开阀不允许语音下发（比确认更严） |
| 6 | 关掉燃气阀 | 先问 → 确认后执行 | 关阀也需确认现场情况 |
| 7 | 解锁入户门锁 | 先问 → 确认后执行 | 入户安全动作 |
| 8 | 撤防 | 挂起等待确认，此时一条指令都没下发 | 安防撤防 |
| 9 | 确认 | 释放第 8 步 | **口头确认**：不用伸手点屏幕，适合视力退化/卧床场景 |
| 10 | 关闭卧室主灯 | 执行 | 幂等起点 |
| 11 | 关闭卧室主灯（再说一遍） | 提示"已去重，未再次下发" | 老人重复说同一句是常态，不是 bug |
| 12 | 打开所有插座 | 整批拒绝 | 批量里混着燃气电磁阀，一步都不发 |
| 13 | 布防 | 直接执行 | 反向验证：安全动作不被过度拦截 |

## 三、演示时要说清的边界（不要临场编）

1. **设备是模拟的**：本轮无真实设备参与（见 `devices/inventory.md`），危险动作一律只在虚拟实体上演示（方案 R6）。
2. **确认门禁会让体验变"慢"**：这是刻意的。本项目要证明的是"哪些动作不该被执行"，不是"回应多快"。
3. **性能数字**：只报 `reports/` 里带口径标注的数字；唤醒率、远场指标本项目没有测，也不声称。
4. **不接厂商云**：各家庭生态的云端接口都不在范围内（企业主体准入，个人拿不到），
   只走本地 Home Assistant 集成。
5. **音频不出本机**：ASR 用本地 faster-whisper；`--loud` 之外不会外放，TTS 落 WAV 文件。

## 四、录屏脚本（若要做 demo 视频，13 步里挑 5 步就够）

1. `python -m hvsl.cli doctor`（30 秒，证明可跑）
2. 第 4 步"打开电暖器" → 展示**待确认**且设备状态未变
3. 第 9 步"确认" → 展示口头确认释放
4. 第 11 步重复指令 → 展示去重
5. `python -m hvsl.cli audit --trace <第4步 trace>` → 展示留痕可反查
   （trace id 在每步输出里，`var/demo_run.json` 也有全量）

> 录屏里请保留 `[待确认]` / `[已拒绝]` / `[已去重]` 的原文提示，
> 这三行就是本项目的全部论点。
