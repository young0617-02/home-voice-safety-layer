## 3. 30 条队列的构造规则（确定性、可复现）

- 城市：一线 5、新一线 7、二线 10、三线及以下 8（一线+新一线 = 12，符合 ≤12）。
- 组别：老人 8、儿童 6、纯危险设备 6（合格 20）；待定 6（4 组配额溢出 + 1 设备不足 + 1 城市超限）；不合格 4（2 排除项 + 2 H1 未过）。
- H1–H4：严格按 `docs/用户验证包-v0.1.md`；纯危险设备组按默认等价口径（仅成年人 + ≥1 危险设备 + 有痛点），`--strict-h3` 可复算。
- 三档：A6 / B7 / C7，按报名顺序轮转。
- 每条记录标 `derived=1`、`derivation_model=g1-v0.1`。

## 4. 使用边界（必须遵守）

- 只能写“**推导队列**”，不能写“真实报名 30 份”或“访谈 20 户已完成”。
- 不能把推导结果写进对外材料、融资材料、B2B 一页纸。
- 不能据此宣称 G1 通过；只能说“在假设参数下，筛选与判据链路可跑通，结论为 X”。
- 真实 G1 仍需真人报名与访谈；推导数据只用于**提前发现流程/口径问题**。
