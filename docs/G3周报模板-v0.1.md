# G3 周报模板 v0.1

> 用途：G3 内测每周五的**一页周报**，供团队看进度、看异常、做决策。
> **本模板不含任何数据**：所有数字位置写 `__`，填空时替换；不要保留占位符交付。
> **三条硬边界**：① 不写真实姓名/门牌/小区/联系方式；② 不把 `synthetic=1` 的 demo 当真实；③ **未采集不写"通过"**。

---

## 2. 填写规则（逐项）

| 项 | 规则 |
|---|---|
| 样本行 | 写"10 户（有效 __ / 退出 __ / 补位 __）"；分母固定 10，不因退出改小 |
| 周活 | 按**周**算：本周至少 1 天 `active=1` 的户数 / 10；两周不能合并成一个数 |
| 完成率 | `confirm_completed / (confirmed+expired+denied+cancelled)`，排除 `not_required`；分子分母都写出来 |
| 误报率 | `false_positive / confirm_started`；分母是确认发起数，不是全部指令数 |
| 越权 | 写"次数 + 户号 + 处置状态"；只要 >0 就是安全红线，不能写"轻微""可接受" |
| P90 | 写秒数 + 样本量 `n=__`；`n<10` 写"样本不足"，不硬报 |
| 上周列 | 第一期写"—"；第二期必须填，便于看趋势 |
| 异常 | 每行只写编号与类别，不写用户原话全文；关闭要有复测证据 |
| 原话 | 每期 3 条，已脱敏；同一户最多 1 条；不引用孩子说的话 |
| 下周动作 | 最多 3 条，每条有负责人与截止日；不写"持续观察"这种没有动作的话 |
| 决策事项 | 只写需要别人拍板的；自己能定的直接做，不占这一栏 |

---

## 3. "不得写"清单

1. **不写真实姓名、门牌号、小区、联系方式、微信昵称、车牌**。
2. **不写原始语音文本**；引用原话必须脱敏，并标"用户原话（已脱敏）"。
3. **不把 `synthetic=1` / demo 数字当真实**；不写"demo 里已经达标"。
4. **不把"未采集"写成"通过"或"暂无异常"**；缺数据就写"未采集"。
5. **不把分母为 0 写成 0%**；写 `—` 并说明"无确认发起，无法计算"。
6. **不把越权下发写成"误报"或"体验问题"**；两者分母与后果不同。
7. **不写"已修复"而没有复测记录**；修复必须附复测日期与 0 越权证据。
8. **不写未验证的功能承诺或可用时间**；不写"下周就能支持××"。
9. **不写其他户的可识别信息**；户号之外不出现任何能定位到人的描述。
10. **不写"感觉""大概""明显好转"替代数字**；没有数字就写"未采集"。
