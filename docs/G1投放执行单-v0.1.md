## 2. 发帖（需登录；约 5 分钟）

1. 打开 `https://bbs.hassbian.com/` → 登录（或微信扫码）。
2. 进入 `forum-38-1.html` → “发新帖”。
3. 分类选：**智能音箱 / 插件集成 / 讨论**（三选一，不要选“求助”）。
4. 标题 + 正文：复制 `docs/招募帖与问卷-v0.1.md` §1 的 **HA 中文论坛版**。
5. 置顶评论：放问卷链接 + “不推销、只访谈、¥50 红包或一次免费上门配置”。
6. 注意：论坛支持 Markdown，需在纯文本模式加 `[md]...[/md]`；**不要发纯广告**。

## 5. 问卷（问卷星，约 10 分钟）

1. 打开 `https://www.wjx.cn/` → 免费注册/登录。
2. 新建“报名表单” → 导入 `docs/问卷导入模板-G1.csv`（**先删除末尾 `#` 注释段**）。
3. 按模板里 14 条注意事项：Q5 的“都没有”、Q6 的“只有成年人”、Q9 的“都没有”设为互斥；Q12-1 单选、Q12-2 单行文本且加显示条件。
4. 表单页首加一句：“联系方式仅用于约访谈，访谈结束后 30 天内删除。”
5. 发布，复制链接/二维码，填进帖子置顶评论。

## 6. 导出与交回（约 2 分钟）

1. 问卷星 → 数据 → 下载 → Excel/CSV（UTF-8）。
2. 保存为 **`var/g1/responses.csv`**（覆盖即可）。
3. 我跑：
   ```bash
   .venv/Scripts/python.exe scripts/g1_screen.py --input var/g1/responses.csv --out-dir var/g1
   ```
4. 产物：`var/g1/screened.csv`、`summary.json`、`roster.md`（真实 20 户名单 + A/B/C）。
