## 0. 一页决策摘要

| 问题 | 结论 |
|---|---|
| 做什么 | **家庭高风险语音指令的确认与审计层**（门锁/燃气/总电/大功率/撤防/老人呼叫），不是通用助手 |
| 先打哪个市场 | 已用 **Home Assistant** 的中文家庭（有老人/儿童 + 危险设备） |
| 怎么卖 | 软件订阅 **¥99–199/年** 或 **¥299 买断**；第一版不卖硬件 |
| 多久验证 | **90 天**；第 4 周必须有 ≥10 个预付，否则停 |
| 技术底座 | 复用现有 `hvsl` 的 engine/gate/idempotency/audit，改造成可安装 HA 集成 |
| 最大风险 | 人群太小、付费意愿不足、HA 集成真机未跑通、合规（声纹/儿童） |
| 明确不做 | 通用闲聊、音箱/中控屏整机、强制订阅、厂商云 OAuth 承诺 |

**一句话**：把"宁可少做，不可多做"做成一个可安装、可收费、可审计的家庭安全层；先证明有人付钱，再谈硬件。

> **技术清单另发现 3 个必须先修的隐藏缺口**：① 未评审实体（燃气/大功率 switch）默认落 `low`、**无确认直接下发**；② HA 真机下发调用了现代 HA 不存在的同步 `hass.services.call(blocking=True)`，测试把缺口遮住；③ HA 的 LLM 模式根本没传 `cross_check`，影子纠偏未启用。详见 `docs/技术可行性清单-v0.1.md` §2 与本文 §7 R9–R11。
> **2026-11-03 实施状态**：以上 3 条 + pending 持久化已修复；P0 六项、P1-1/P1-3/P1-4/P1-5、P2-2、R12 隐私闭环、文档/评测一致性已落地，全量 **478 passed / 2 skipped**、`ruff check .` 全绿、`sync_vendor --check` 与 `gen_inventory --check` 一致。**HA 真机 9/9 + 附加 3/3 + 蓝图 3/3 + soak 1/1 PASS**：Docker Hub `homeassistant/home-assistant:stable` 真实容器完成 onboarding → 向导（20 候选）→ 危险动作挂起 0 下发 → 确认 1 次 → 重启恢复 → 重复拒绝 → 审计导出 → 卸载无残留 → 断网本地执行；CSV 635 行脱敏、50/50 低风险、10/10 危险挂起、通知动作 confirm/cancel 均通过（证据见 `docs/HA真机冒烟结果-v0.1.md`）；`2025.1` 同级全 PASS（pydantic 2.10.4），`2025.2.4` 同等全 PASS（pydantic 2.10.6，9/9 + 附加 3/3 + 蓝图 3/3 + soak 1/1）。**未完成/未验证**：HA 2024.6 依赖不兼容（自带 pydantic 1.10.15，多版本矩阵见 `docs/HA多版本矩阵-v0.1.md`）、2025.2 滚动 tag 镜像未注册、2025.3+ 未测、notify 真投递（HA 2026 legacy 平台不可用）、真实设备、HA 内 ASR/TTS 接入；HA 2026 blocking 警告已清零（executor 懒加载）。对外不得宣称“生产可用”。

## 1. 定位

### 1.1 一句话

> 当你说"开大门""关燃气""全屋断电"时，它不会立刻执行，而是先确认、再执行、全程留痕。

### 1.2 目标用户（按优先级）

| 优先级 | 人群 | 特征 | 为什么先选 |
|---|---|---|---|
| P1 | **有老人/儿童 + HA + 门锁/燃气** 的技术中产家庭 | 已自建 HA，愿为安全付费，能自己装集成 | 获客成本最低，痛点最具体 |
| P2 | 适老化改造 / 家装前装 / 保险 | 批量、有预算、需要审计报告 | 单笔金额大，但周期长 |
| P3 | 纯极客 | 传播强、付费弱 | 只做口碑，不做收入 |

### 1.3 明确不做

- 不做通用闲聊、百科、音乐、购物。
- 不做音箱/中控屏整机（路线 3）。
- 不做强制订阅（Humane 的反面教材）。
- 不做需要厂商云 OAuth 的承诺（认证与 API 变动会把承诺打穿）。
- 不在第一版做唤醒词/远场/方言。

## 2. 调研结论（压缩）

### 2.1 三张事实表

**开源/独立**

| 对象 | 价格/形态 | 关键结论 |
|---|---|---|
| HA Voice PE | **$69 / €59**，ESP32-S3 卫星 | 本地优先有市场，但官方自称 Preview；**本地聚焦式中文缺位** |
| Nabu Casa Link | **$6.50/月、$65/年**，31 天试用、不强制 | "本地优先 + 可选云 + 硬件"能养活团队 |
| HA Green | **$199 / €179** | C 端要开箱即用，不能要求 pip install |
| Rhasspy / Mycroft | 均已 archived | 纯开源语音栈难成大众产品 |

**国际巨头**

| 对象 | 收费 | 关键结论 |
|---|---|---|
| Alexa+ | Echo 无免费层；Prime $14.99/月含；Standard **$19.99/月** | 语音入口转向订阅 |
| Gemini for Home | 免费 + 付费两档 | 同上，价格未公布 |
| Apple Home/Siri | iCloud+ 增值 | **开门前必须先解锁手机**——危险动作确认是共识 |
| Matter | 标准 | 解决互通，**不定义语音/语义层** |
| Humane AI Pin | **$699 + 强制 $24/月** | 贵 + 强制订阅 + 可被手机替代 → 停服 |
| Rabbit R1 | **$199** | "更差的手机" |

|---|---|---|

| 天猫精灵 | 音箱 + 开放平台 | **1100 品牌 / 4900 型号 / 119 品类** |

| 变现 | 硬件 + 全屋定制/安装/维保 + 云/模组/认证 | **订阅制无公开证据** |
| 市场数字 | — | IDC/Canalys 中国区出货量**未取到**，不编造 |

### 2.2 六条规律

1. 语音入口正在从免费入口变成"硬件毛利 + 订阅"。
2. "本地优先"要配"可选云"，用户为远程/备份/云语音付费，不为"本地"本身付费。
3. 大厂在危险动作上普遍保守（Apple 先解锁、Alexa 默认不许解锁、HA core 无二次确认），**这是标准与巨头的共同取向**。
4. AI 硬件的死法一致：贵、强制订阅、可被手机替代、体验不达预期。
5. 国内 C 端胜负手是生态与渠道，不是算法。
6. 中文语音门槛在远场/方言/唤醒/低成本，开源侧仍是短板。

## 3. 路线选择

| | 路线 1：HA 安全策略层 | 路线 2：语音卫星硬件 | 路线 3：通用助手/整机 |
|---|---|---|---|
| 形态 | HA 集成 + 手机网页/App | ESP32-S3 + 双麦 + 物理键 | 音箱/中控屏 |
| 价格 | ¥99–199/年 或 ¥299 买断 | ¥299–499 | 市场价/补贴 |
| 周期/现金 | **8–12 周 / < ¥2 万** | 6–9 个月 / ¥30–80 万 | 12 个月+ / 千万级 |
| 认证 | 无 | SRRC/CCC/CTA | 全套 + 生态认证 |
| 胜率 | **中高（窄人群）** | 中 | 极低 |
| 结论 | **先做** | 验证后再定 | **不做** |

**为什么是路线 1**：复用现有 90% 代码；无需硬件与认证；8–12 周可收到第一笔钱；失败成本可控。硬件不是不能做，而是**不能先做**——Humane 已经用 $699 + 强制订阅演示了顺序错误的代价。

## 4. 产品定义（MVP-Paid）

### 4.1 用户旅程（首次 5 分钟）

```
安装（HACS/手动） → 配置向导（选危险设备/确认渠道/保留期）
 → 说"开大门" → 系统判定 confirm → 语音二次确认 + 手机推送
 → 确认（令牌单用途/TTL/错误计数） → 执行 → 手机收到结果 + 审计可查
```

### 4.2 六个必须做对的机制

| # | 机制 | 现有底座 | C 端要求 |
|---|---|---|---|
| 1 | 风险定级 low/confirm/deny | `risk.py` + `risk_policy.json` | 危险设备由用户勾选，清单可解释 |
| 2 | 整计划挂起，0 下发 | `engine._park` + `gate` | 确认前绝不动作 |
| 3 | 令牌单用途 + TTL + 会话绑定 | `gate.take` | 加**错误尝试计数与冷却**（对标 Matter WrongCodeEntryLimit） |
| 4 | 未知结果绝不重发 | `idempotency` | 修 `stale_seconds` 死配置与 in_flight 永久阻断 |
| 5 | 多渠道确认 | 无 | 语音 + 手机推送 + 物理键（至少两种） |
| 6 | 可导出审计 | `audit` | 一键导出 CSV/JSON；默认不存原始音频 |

### 4.3 MVP 范围（只做这 6 项，其余不做）

1. 打包与安装（hvsl 随集成分发，不要求 `pip install`）。
2. policy 与 device catalog 的查找顺序（配置目录/集成目录/用户覆盖）+ **未评审实体默认 `confirm` 兜底**（防止燃气/大功率 switch 落默认 `low` 直接下发）。
3. config_flow 校验 + options 变更后 reload。
4. services 返回值 + sensor 多会话 + 隐私（token/原文不进 state attributes）。
5. pending 持久化 + 幂等 unknown 永不自动重发。
6. 确认闭环（语音/推送/物理键）+ 审计导出。

> 技术细节与逐项人日见 `docs/技术可行性清单-v0.1.md`。
