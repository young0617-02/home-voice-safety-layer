# G1 模拟访谈记录 v0.1

> ## ⚠️ 合成演练，仅用于检验提纲，不是用户证据
>
> **本文件 5 位受访者全部为虚构合成角色**，由《用户验证包-v0.1》§2 的提纲推演生成。
> **不含任何真实用户、真实家庭、真实设备日志、真实录音或真实联系方式。**
> 文中的分数、时长、金额、设备数量均为**模拟值**，只用于检验"记录表能否填满、提纲能否问出具体场景"。
> **禁止**：写入 G1 判据、计入 20 户、对外引用、当作市场数据、当作需求证据。
>
> 用途只有三个：① 让访谈员在真实访谈前完整跑一遍流程；② 找出提纲里问不出具体场景的段落；③ 统一 13 列记录表的填写口径。

## 0. 演练设置

- 每场 50 分钟：0–5′ 行政，5–50′ 六段（破冰 5 / 关键事件 10 / 替代方案 10 / 演示与反应 10 / 费用形式 5 / NPS 5）。
- **例外（本身就是要检验的结论）**：P-S04 不合格场在第 12 分钟终止，P-S05 待定场只做 15 分钟备选确认。这两类**不应该**做满 45 分钟——记录到终止点为止，强行做满反而会污染样本。其余三场按完整 50 分钟走完。
- 线上为主；S1 为上门场（老人组 2 户上门的规则）。
- 演示用本地模拟设备，不接触受访者家中设备。
- 标注约定：
  - **【场景】** = 该问拿到了带时间锚的具体事件，可直接进"关键场景（1句）"列；
  - **【失效】** = 该问没得到可用信息（抽象回答、答非所问、被访谈员抢话）；
  - **【引导】** = 访谈员说漏嘴，用户随后改口；
  - **【闭嘴】** = 用户开始讲细节，访谈员停止提问的位置。
- 户号用 `P-S01`…`P-S05`，`S` 表示 synthetic，**不与正式 20 户的 P01–P20 混用**。

## 1. P-S01 · 老人组（上门场）

**合成画像**：某新一线城市，HA 跑在 Docker，可控实体 20–30 个；接入门锁 + 燃气阀；同住 70+ 岁老人，老人白天独处 ≥4 小时；子女是 HA 的主要配置者。

### 45′ 要点记录

- **0–5′ 行政**：子女开门，老人在客厅。录音单独同意——老人先说"问我儿子"，子女说"录吧"，访谈员坚持让老人自己回答，老人点头说"可以录"。备注：`录音=同意（老人本人确认，子女在场）`。
- **5–10′ 破冰**
  - B1 → 老人："我早上喊'开灯'，它有时候开有时候不开。"【场景：早上、开灯、时灵时不灵】
  - B2 → 子女代答"当时想自己控制，不想被一家绑死"；访谈员追问老人"你当时同意吗"，老人："我听不懂，他们弄的。"【场景：决策人≠使用者】
  - B3 → 老人指向门锁："这个会自己开。"
  - B4 → "最不放心的是门锁，因为上次它自己开了。"【场景】
- **10–20′ 关键事件**
  - K1 → 老人："上个月有一天晚上，我在屋里看电视，门'咔'一声。"【场景：上个月、晚上、门锁自动开】
  - K2 → "没人说话。电视里有人在喊。我儿子在楼上。"设备"开了，没响，也没人知道"。【场景：电视声音→门锁动作】
  - K3 → "我拿凳子顶住门，后来儿子下来把电拔了。"
  - K4 → 老人沉默 8 秒："要是进来人……"访谈员**停住不问**，转向 K5。
  - K5 → "儿子把门锁的语音关了，现在只能手机开。我踏实一点，但我不会用手机。"
  - 访谈员在此处**【引导】**："是不是因为电视里说了'开门'？"老人顺着说"对对"。→ 记录时标注：`电视台词触发为访谈员提示，非用户自述`。
- **20–30′ 替代方案**
  - A1 → "拔电、凳子顶门、儿子手机开。"【动作】
  - A2 → "最烦的是儿子不在家，我进不了门。"
  - A3 → "我记不住，还是会去按面板。"
  - A4 → 子女："试过自动化，老人一说话就误触发，关了。"【场景】
  - A5 → "没单独花钱，就是花时间。"
- **30–40′ 演示 + 反应**
  - 演示 30 秒：说"开门"→ 要求确认 → 说"确认"→ 执行 → 看记录。
  - C1 → 老人："这样好，它先问我一句。"
  - C2 → "门锁要多问，灯不要问。"【场景】
  - C3 → "我不会翻记录，我儿子会看。"
  - C4 → **【失效】** 老人答"我会说'确认'"，但访谈员没有验证"老人是否理解'确认'意味着什么"；老人随后把"确认"说成"确定"。
  - C5 → "如果每次开门都要说两遍，我就不用了。"
- **40–45′ 费用形式**
  - M1 → **【失效】** "不知道，都是孩子交的。"
  - M2 → "门锁是他们买的，我不知道多少钱。"
  - M3 → "买断吧，别年年交。"（但**决策人不是老人**）
  - M4 → "要我出钱就不值。"
  - M5 → "没了就让儿子拿钥匙。"
- **45–50′ NPS**
  - N1 → **【失效】** 老人："推荐给谁？我朋友都不用这个。"
  - N2 → "我说不上来。"
  - 访谈员改用生活化问法："你会不会跟一起跳舞的老姐妹说'我家这个门锁会先问一句'？"→ "那会说。"
  - N3 → "跟老人说，不跟年轻人说。"

### 诊断

- **哪一问问出了具体场景**：**K1 + K2**。时间锚（上个月、晚上）+ 触发源（电视台词）+ 设备行为（门开了、没响）三要素齐全，可直接填表；B4 的"最不放心门锁"提供了事件入口。
- **哪一问失效**：**M1/M2（费用支出）与 N1（NPS）**。老人不是费用决策人，也不理解"推荐"这个说法；C4 表面有答案、实际没验证理解，属于**假成功**。
- **提纲改进建议**：① 老人组增加"谁决定买/谁付钱"的固定问句，费用段按决策人记录；② NPS 在老人组换成生活化说法（"会不会跟老姐妹说"），并标注"非标准 NPS，仅方向"；③ C4 必须加一句"你能说说'确认'是什么意思吗"来验证理解，而不是只听"我会说"。

## 2. P-S02 · 儿童组

**合成画像**：某二线城市，HA OS，可控实体 30–40 个；接入门锁 + 大功率插座（热水器）；同住 6–12 岁儿童，孩子会自己用语音，也按过面板；家长是主要配置者。

### 45′ 要点记录

- **0–5′ 行政**：孩子中途跑进画面两次。第一次访谈员**立即暂停录音**，请家长带孩子出去；记录 `HH:MM 儿童进入画面，录音暂停 3 分钟`。第二次孩子抢话"我会开电视"，访谈员不追问孩子，只对家长说"我们继续"。
- **5–10′ 破冰**
  - B1 → 家长："孩子用得比我多，他会喊'开电视''开灯'。"
  - B2 → "整套方案要绑账号，我想自己控。"
  - B3 → "灯、电视、门锁、热水器。"
  - B4 → **【场景】** "最不放心门锁，因为他学会说'开门'了。"
- **10–20′ 关键事件**
  - K1 → "上个星期，他在门口喊了一句'开门'，门真的开了。我在厨房。"【场景：上个星期、门口、孩子喊开门、门开了】
  - K2 → "他在玩，不是真要出去。门开了他也没动。我听到'咔'才跑过去。"【场景：孩子无意图、门执行、家长事后发现】
  - K3 → "我把门锁语音权限关了，改成只有我的手机能开。"
  - K4 → "他才六岁多，真跑出去，楼道没监控。"
  - K5 → "关了语音之后，他自己开不了门，但他会拿我手机试。"
- **20–30′ 替代方案**
  - A1 → "关语音、手机开、教他'这个不能喊'。"【动作】
  - A2 → "最烦的是他拿我手机乱点，我还得设密码。"
  - A3 → **【失效】** 家长答"他答应不喊了"，但同一段里又说"他上周还喊了"——**承诺与行为矛盾**，访谈员没有追问矛盾点。
  - A4 → "设过自动化：晚上十点后门锁语音静音。有用，但白天还是能开。"
  - A5 → "买了个摄像头，三百多。"（已发生支出，可记）
- **30–40′ 演示 + 反应**
  - C1 → "第一反应是终于有人管这个了。"
  - C2 → "门锁、燃气要多问；灯要是也问，孩子会觉得好玩，故意说'确认'。"
  - C3 → "会翻，主要看谁开的、几点。"
  - C4 → **【失效】** "孩子学得快，没问题。"访谈员接受了这个答案，但没有追问"如果孩子故意说确认呢"。
  - C5 → "如果孩子能自己绕过确认，我就关掉。"
- **40–45′ 费用形式**
  - M1 → "Nabu Casa 一年几百，加电费。"
  - M2 → "摄像头、门锁都算安全支出。"
  - M3 → "年费吧，能一直更新。"
  - M4 → "如果孩子能绕过，白送也不要。"
  - M5 → "没了就继续关语音。"
- **45–50′ NPS**
  - N1 → 8 分。
  - N2 → "因为确实解决了一个我怕的事。"
  - N3 → "推荐给有小孩的，不推荐给纯玩设备的。"

### 诊断

- **哪一问问出了具体场景**：**B4 → K1 → K2**。B4 先把"不放心"落到门锁，K1 立刻给出时间锚（上个星期）和触发句（"开门"），K2 补齐"孩子无意图、门执行、家长事后发现"的因果链——这一段是整份提纲里效率最高的一条路径。
- **哪一问失效**：**A3 与 C4**。A3 拿到的是孩子的"承诺"，不是行为，且与用户自己后文矛盾，访谈员没追；C4 得到一个乐观判断就放过，错过了"孩子故意说确认"这个真实风险点。
- **提纲改进建议**：① A3 增加"他答应之后，最近一次又犯是什么时候"的矛盾校验句；② C4 改成情境假设 + 行为追问："如果孩子学会了说'确认'，你觉得他会怎么做？你见过他模仿吗？"③ 儿童在场时的暂停规则要写进速查卡（当前只在异常处理里，访谈员容易忘）。

## 3. P-S03 · 纯危险设备组

**合成画像**：某一线城市，HA Supervised，可控实体 60+；接入门锁 + 燃气阀 + 总闸；无老人儿童；本人是主要使用者，技术型，自建自动化多年。

### 45′ 要点记录

- **0–5′ 行政**：对方先问"你们是哪个团队的、用什么模型"，访谈员一句话带过，直接进开场。录音同意顺利。
- **5–10′ 破冰**
  - B1 → "就我自己用，一天十几次。"
  - B2 → **【失效】** 变成 8 分钟技术史：从树莓派讲到 Supervisor 迁移，访谈员没刹车。
  - B3 → "灯、空调、门锁、燃气、总闸。"
  - B4 → "总闸最不放心，误断一次冰箱全化。"
- **10–20′ 关键事件**（被压缩到 6 分钟）
  - K1 → "上个月改自动化，脚本里少了个条件，半夜把总闸断了。"【场景：上个月、半夜、脚本误断总闸】
  - K2 → "没人说话，是我自己写的规则。冰箱化了一地水。"
  - K3 → "改了脚本，加了个时间窗。"
  - K4 → "最坏就是冰箱、呼吸机这类。我家没有呼吸机。"
  - K5 → "改完踏实了，但我还是不敢让来访的朋友用语音。"
- **20–30′ 替代方案**
  - A1 → "自动化加条件、面板二次确认、关键设备不接语音。"【动作】
  - A2 → "最烦的是每次改完要重新测一遍，一测半小时。"
  - A3 → 不适用（无老人儿童）。
  - A4 → "一直在用自动化和脚本，效果看写得好不好。"
  - A5 → "花时间最多，钱倒不多。"
- **30–40′ 演示 + 反应**
  - C1 → "思路对，但我更关心误报率。"
  - C2 → "总闸、燃气必须问；灯问就是骚扰。"
  - C3 → "会翻，想看触发原文和规则命中哪一条。"
  - C4 → 不适用。
  - C5 → "如果确认窗口太短、或者我说'确认'它听错，我就关。"
- **40–45′ 费用形式**
  - M1 → "Nabu Casa、电费、硬件，一年不少。"
  - M2 → "燃气报警器、门锁都算。"
  - M3 → "买断，我不喜欢年费。"
  - M4 → "如果只是加个确认弹窗，不值。"
  - M5 → "没了就自己写自动化。"
- **45–50′ NPS**
  - N1 → 6 分。
  - N2 → "对我这种人来说，自己写脚本也能做到一部分。"
  - N3 → "推荐给不想写脚本的人，不推荐给爱折腾的。"

### 诊断

- **哪一问问出了具体场景**：**K1**。一句"上个月改自动化，脚本少了个条件，半夜断了总闸"就给出了时间、原因、后果，是这段唯一有效的信息；B4 的"总闸最不放心"起了定位作用。
- **哪一问失效**：**B2**。技术型用户会把"为什么选 HA"变成技术史，直接吃掉关键事件段 4 分钟；A4 也容易变成方案评审。整场的关键事件段被压到 6 分钟，是全套提纲里最危险的失真点。
- **提纲改进建议**：① 给访谈员一句固定刹车话："这段很精彩，我们留到后面；先回到上个月那次断电。"② 关键事件段设为**不可压缩**，超时优先砍 B2 和 A4；③ C1 的"第一反应"对技术型用户要改成"你会先测什么"，否则只会得到评价而非行为。

## 4. P-S04 · 不合格（访谈中才识别）

**合成画像**：某三线城市，HA 装在**办公室/工作室**，不是自住家庭；可控实体 30+；有门锁但装在办公室；无老人儿童同住。报名时 Q3/Q4/Q5 都通过，Q6 选了"只有成年人"——按问卷规则本应在提交时结束，但对方是通过私信报名、人工录入时漏判。

### 45′ 要点记录（实际 12 分钟结束）

- **0–5′ 行政**：开场顺利；问到"HA 跑在哪"时对方说"在我工作室，家里也有一套但没怎么用"。
- **5–12′ 复核**：
  - H1 复核 → "工作室的跑了两年，家里的装了没怎么用。"
  - H2 复核 → "门锁是工作室的。"
  - H3 复核 → "家里没老人，孩子周末来。"
  - 排除项复核 → **命中"非自住家庭"**（主力环境是办公室）→ 访谈员停止正式访谈。
- **结束话术**："聊下来你这套主要用在工作室，按规则这次就不占用你时间了，谢谢你。"（不进入关键事件段，不记录任何访谈内容）
- **红包**：**不发**（排除项不占红包预算，与招募文档 §7.8 一致）。
- **记录**：只写 `排除：非自住（主力环境为工作室）`，不计 20 户，名额补招。

### 诊断

- **哪一问问出了具体场景**：**无**。这场在 H1 复核阶段终止，没有进入关键事件段，因此**没有产生任何可用场景**——这是正确结果，不是失败。

## 5. P-S05 · 待定（备选池）

**合成画像**：某新一线城市，HA Docker，可控实体 40+；接入门锁 + 燃气 + 大功率；无老人儿童，本人主用；H1–H4 全过。但纯危险设备组 6 户已满、一线/新一线也已到 12 户上限，因此进备选池。

### 45′ 要点记录（只做 15 分钟"备选确认"，不做完整访谈）

- **0–5′ 行政**：说明"今天先做 15 分钟确认，如果后面有名额再约完整 45 分钟"，对方同意。
- **5–10′ 复核**：H1–H4 逐项复核通过；确认纯设备组名额已满。
- **10–15′ 三个问题**（只用于判断"值得留池"）：
  - "如果两周内有名额，你还能约吗？" → "能，晚上都行。"
  - "你家最不放心哪台设备？" → "燃气，我怕它把'关'听成'开'。"
  - "如果最后没约上，你会介意吗？" → "不介意，你们忙。"
- **结束**：告知进备选池、有人退出按序补、不承诺时间；**不发红包**（未做完整访谈，红包在完成访谈后发）。

### 诊断

- **哪一问问出了具体场景**：**无完整场景**。15 分钟里只拿到一句方向性表述（"怕把'关'听成'开'"），**不足以填"关键场景"列**，也不应硬填。
- **哪一问失效**：**整场都不该按 45′ 提纲走**。若对待定户做完整访谈，会出现两个问题：① 花了 50 分钟却不计入 20 户，成本浪费；② 访谈员容易因为"聊得挺好"而把它顺手转成"合格"，直接破坏配额（招募文档 §5 硬规则 2 明令禁止）。
- **提纲改进建议**：① 待定户只做 15 分钟"备选确认"三问，不做六段；② 记录表增加一个明确状态（备注写 `待定-未完成`），分析时按状态过滤；③ 备选池排序规则写死（报名时间 + 组别缺口），不按"聊得好不好"插队。

## 6. 五场演练的共同发现

| 发现 | 出现在 | 后果 |
|---|---|---|
| 关键事件段最容易被挤压 | S01（情绪停顿）、S03（技术跑偏） | 一旦压缩，整户记录就只剩态度，没有事件 |
| "表面有答案"最容易骗过访谈员 | S01 的 C4、S02 的 C4 | 用户说"没问题"，实际是没理解或没想过 |
| 决策人 ≠ 使用者 | S01（老人不用付钱、不用手机） | 费用与 NPS 记在错误的人头上 |
| 用户自述会与行为矛盾 | S02 的 A3 | 不追问矛盾点，记录就写成"孩子答应不喊了" |
| 排除/待定识别越晚，成本越高 | S04（12 分钟）、S05（15 分钟） | 时间浪费是小事，**污染样本**是大事 |

## 7. 提纲修订建议 5 条

> 只改"问法"，不改 H1–H4 门槛、不改 20 户配额、不改判据阈值。

1. **把抽象问题改成时间锚定问题。** "你担心吗""有没有遇到过"一律不问，改成"最近一次是什么时候""上一次用它是什么时候"。用户给判断（"我觉得挺危险"）时，访谈员必须用固定句拉回："能讲一下最近一次具体是什么时候吗？"——S01 和 S02 的事件都是被这一句逼出来的。
2. **关键事件段加"倒放时间线"三问，并设为不可压缩。** 在 K2 后固定补三句："当时几点？""谁先开口？""设备当时是什么反应（灯、声音、动作）？"S01 的"电视台词→门锁开"、S03 的"脚本少条件→半夜断闸"都是靠这三问才变成可核查的序列。超时优先砍破冰 B2 和技术讨论 A4，**不砍关键事件**。
3. **替代方案段先问行为、再问原因。** 顺序固定为"你实际做了什么 → 哪个最烦 → 为什么"，不要先问"你怎么看"。S02 的 A3 就是反例：先问"孩子愿意遵守吗"，得到的是承诺；改成"他答应之后，最近一次又犯是什么时候"，才拿到行为。
4. **演示后先问"哪一步多余"，再问"哪类愿意多问一句"。** 先问优点会得到社会赞许的"挺好的"；先问多余，才能拿到真实的摩擦点（S01 的"每次开门说两遍就不用"、S02 的"孩子会觉得好玩，故意说确认"）。C5"什么情况下你会关掉它"必须追问到具体触发条件，不接受"看情况"。
5. **费用段与 NPS 段按"决策人"分流，且先问已发生支出。** 顺序：已发生支出（M1/M2）→ 形式偏好（M3）→ 消失后会怎样（M5）。老人组若子女是决策人，费用与 NPS 记在子女口径并标注；老人本人只记"会不会跟同龄人说"（非标准 NPS，仅方向）。**任何情况下不问金额、不报价。**

### 附：不建议改的 3 处（防止过度修订）

- **不改六段时间配比**：5/10/10/10/5/5 的分配在五场演练里都能走完；问题不在时长，在访谈员是否守时。
- **不改"不解释、不辩护"**：S03 的跑偏不是因为规则不清，是因为没有刹车句——补话术，不放松规则。
- **不改 13 列记录表**：五场都能填满；填不满的场次（S04/S05）本来就不该进 20 户表。加列会让历史记录不可比。
