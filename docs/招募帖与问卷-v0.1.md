**判定规则（H1–H4 从答案计算）**

- **H1 已用 HA**：`Q2 ∈ {3–12 月, >12 月}` ∧ `Q3 ∈ {HA OS, HA Green, Supervised, Docker}` ∧ `Q4 ∈ {10–30, 31–80, >80}`
- **H2 有危险设备**：`Q5 ∩ {门锁, 燃气阀或燃气报警联动, 总闸或空开, 大功率插座} ≠ ∅`
- **H3 有老人或儿童**：`Q6 ∩ {65+ 老人, 6–12 岁儿童, 3–6 岁儿童} ≠ ∅`
- **H4 有痛点**：`Q9 ≠ 仅「都没有」` ∨ `Q10 ≥ 4`
- **排除项**：Q3=记不清 / Q12 录音意愿=不接受 / 命中"从业者、亲友同事、非自住、已用同类产品"（人工核对）

```text
# 输入：answers[Q1..Q12]；quota{老人,儿童,纯危险设备} 为剩余名额
function decide(answers):
    if answers.Q12_recording == "不接受": return "不合格（结束并感谢）"
    if answers.Q3 == "记不清": return "不合格（结束并感谢）"
    if answers.Q4 == "0–9": return "不合格（结束并感谢）"
    if answers.Q5 == ["都没有"]: return "不合格（结束并感谢）"
    if answers.Q6 == ["只有成年人"]: return "不合格（结束并感谢）"

    H1 = answers.Q2 in {"3–12 月", ">12 月"} and answers.Q3 in {"HA OS","HA Green","Supervised","Docker"} and answers.Q4 in {"10–30","31–80",">80"}
    H2 = len(set(answers.Q5) & {"门锁","燃气阀或燃气报警联动","总闸或空开","大功率插座"}) >= 1
    H3 = len(set(answers.Q6) & {"65+ 老人","6–12 岁儿童","3–6 岁儿童"}) >= 1
    H4 = (len(set(answers.Q9) - {"都没有"}) >= 1) or (answers.Q10 >= 4)

    if not (H1 and H2 and H3 and H4): return "不合格"

    has_child = bool(set(answers.Q6) & {"6–12 岁儿童", "3–6 岁儿童"})
    group = "老人" if "65+ 老人" in answers.Q6 else ("儿童" if has_child else "纯危险设备")
    danger = len(set(answers.Q5) & 危险四项)
    if group == "纯危险设备" and danger < 2: return "待定（备选池）"
    if quota[group] <= 0: return "待定（备选池）"
    if answers.Q1 in {"一线","新一线"} and 一线新一线已满(12): return "待定（备选池）"
    return "合格"
```

**三档判定含义**：合格=进 20 户名单；待定=硬门槛全过但名额/城市/设备数不匹配，进备选池，有人退出按序补；不合格=明确感谢并结束，不承诺后续。

## 7. 风险与合规提醒

1. **不承诺产品功能**：只说"我们在做/在验证"，不说"一定会有""下月上线"；不演示未完成功能，不承诺适配某品牌设备。
2. **不收集与访谈无关的个人信息**：只要联系方式、家庭结构、HA 形态、设备类别；不收集身份证、门牌号、门锁品牌序列号、孩子姓名学校。
3. **红包与购买解耦**：¥50 在访谈结束即发，不看是否付款；话术、置顶评论、访谈前口头说明三处统一；禁止"填完才发""买了才发"。
4. **录音需单独同意**：Q12 的录音意愿单独勾选，访谈开始前口头再确认；只接受笔记的户全程不录音；录音本地加密、访谈后 30 天内删除，转写文本去标识。
5. **儿童信息不追问细节**：只问年龄段与"是否会自己用语音/碰开关"；孩子在场时不录音、不拍摄；不追问学校、班级、常去地点。
