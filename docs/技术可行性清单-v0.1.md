## 1. 目标与完成定义（什么叫“可安装、可收费”）

以下 7 条全部满足，才算 v1.0 可收费：

1. **装得上**：HACS 自定义仓库或手动复制 `custom_components/home_voice_safety/` 即可；**不要求用户 `pip install hvsl`**；HA 重启日志无 `ModuleNotFoundError`。
2. **配得快**：配置向导 ≤5 分钟；自动列出候选实体，用户只需勾选/确认危险设备；默认 policy 与 catalog 随包提供。
3. **用得通**：4 个 service（`handle_utterance` / `confirm_action` / `cancel_action` / `list_pending`）在 Developer Tools 和 automation 里可调用并**拿到 response**；3 个 sensor 正常显示。
4. **确认闭环**：危险指令 → 语音二次确认 / 手机推送 / 物理键 → 确认后**只下发一次**；取消、超时、重放均不下发，且有留痕。
5. **审计可导出**：按 trace 导出 CSV/JSON 到 `config_dir`，含风险类别、确认状态、下发结果；默认脱敏 utterance。
6. **重启不丢**：HA 重启/集成 reload 后，未过期待确认动作仍可确认；`in_flight`/unknown **永不自动重发**，但可见、可人工裁决。
7. **卸得干净**：卸载后 service/entity 不残留；DB/导出文件按选项保留或删除；配置条目可迁移。

**收费的技术假设【推断】**：离线签名 `license.json`（Ed25519），只校验 premium 功能（审计导出、保留期、推送渠道），**安全门禁与幂等永不因 license 失效而降级**；不 phone-home，符合 README §9 的隐私边界。HACS 本身不做付费，收费走独立授权文件/私有安装包，不改变开源集成本体。
