## 5. 已知坑（本机环境，省你一遍调试）

1. **cublas DLL**：Windows 上 ctranslate2 需要 `nvidia/cublas/bin` 里的 `cublas64_12.dll`、
   `cublasLt64_12.dll` 可见，否则 GPU 报 "cublas64_12.dll is not found"。
   `pipeline/_asr_worker.py::fix_cuda_dll_path()` 已做 PATH 兜底，并会在 CUDA 起不来时
   自动退回 `cpu/int8`，**报告里如实标 `device`**。
2. **模型路径**：`ASR_MODEL_DIR` 给"缓存根"（`.hf-cache/hub`）或"快照目录"都能识别
   （`resolve_model_ref` 会找 `model.bin`）；给错不会联网下载——`HF_HUB_OFFLINE=1`。
3. **Git Bash 路径**：给子进程传 Windows 路径时用正斜杠形式，避免 `/tmp` 类参数被转换。
4. **typing_extensions / anyio**：本机全局环境里 `fastapi.testclient` 起不来
   （`cannot import name 'sentinel' from 'typing_extensions'`），与本项目代码无关；
   因此 HTTP 契约测试打的是框架无关的 `hvsl.server.handle_request`，FastAPI 适配器测试会自动跳过。
