# ASR 字错率（CER）实测 · 合成语音

- 生成时间：`2026-11-04T16:50:49+08:00`
- 模式：`tts`（synthetic=true）
- 采样：10 条（内置家居指令短句，参照文本已知）
- 环境：device=`cuda` / compute_type=`float16` / beam_size=`1`
- 归一化（原样口径）：opencc 繁转简 → NFKC（全角折叠）→ 去空白 → 去中英文标点 → ASCII 小写 → 只保留 Unicode 字母（含 CJK）与数字；ref 与 hyp 共用同一函数
- 归一化（主口径）：在原样口径基础上，ref 与 hyp 再走同一套数字等价归一化（中文数字→阿拉伯数字、`百分之X`→`X%`）；两侧同规则，`一下`→`1下` 这类误伤同向发生
- 平均 CER = 每条 CER 的算术平均；pooled CER = 总错误 / 总参照字数；总字数 = 数字归一化后的参照字符数；S/D/I = 替换/删除/插入

## 三、边界

- 本文件数字来自本机真实运行：TTS 为 Windows SAPI 本地合成，ASR 为 faster-whisper 本地转写，音频只在本地读写。
- **合成语音不等于真人**：不覆盖口音、语速变化、远距离拾音、家庭噪声、多人同时说话。
- 10 条短句是小样本，只能说明“在清晰近场的已知文本上错字有多少”，不能外推成家庭场景可用。
- 数字写法已做等价归一化（中文数字→阿拉伯数字、`百分之X`→`X%`），原样 CER 同时保留；两者差异主要来自数字写法，**归一化后才是声学错字口径**。归一化是纯字符串替换，`一下`→`1下`、`万一`→`10001` 这类误伤会出现，但 ref/hyp 同规则、同向变化，不改变 CER 差异。
- 真人 8kHz 样本（OSR）的参照文本仍需人工逐条核对，因此**真人 CER 仍未实测**；本轮没有伪造 OSR refs，也没有拿转写结果反推参照。
- 单独一个模型的 CER 更低，不代表整条决策链路通过率更高；决策还受词表与歧义处理影响。
